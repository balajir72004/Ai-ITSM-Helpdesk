Wi-Fi and Network Troubleshooting Guide

Common Network Problems

Employees may experience Wi-Fi disconnections, slow internet access, or an inability to connect to the corporate network.

Unable to Connect to Wi-Fi

1. Confirm that Wi-Fi is enabled on the device.
2. Verify that the correct network name is selected.
3. Check whether other devices can connect to the same network.
4. Disconnect from the network and reconnect using the approved credentials.
5. Restart the computer if the connection problem continues.
6. Check whether the network is experiencing a reported outage.

Slow Internet Connection

1. Check whether multiple applications are consuming network bandwidth.
2. Move closer to the authorized wireless access point if appropriate.
3. Disconnect unnecessary network-intensive applications.
4. Check whether the problem affects other devices.
5. Retry the connection after a short interval.

Corporate Network Access

Use only authorized corporate network credentials.

Do not bypass network security controls or connect unauthorized devices to the corporate network.

When to Contact IT Support

Contact IT Support if the network remains unavailable or repeatedly disconnects.

Provide the network name, device type, approximate time of the problem, and any displayed error message.
